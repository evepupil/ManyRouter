## 项目目标

ManyRouter 统一管理多个 New API 站点的供应商、分组、策略和价格，根据可信的真实流量与主动测评维护固定及自定义 Auto，并向用户提供可解释、价格稳定、能够自动避开异常供应商的 AI API 服务。

## 交付边界

- M0 完成单站真实接入，禁止用模拟 New API 代替退出验收。
- M1 完成可人工运营的多站产品，固定 Auto 可以由运营人员维护成员。
- M2 只生成评分和调整建议，真实分组仍由运营人员决定。
- M3 同时交付固定 Auto 自动调整和 New API 用户页面，形成可用的自动运营 MVP。
- M4 完成正式接入、兼容验证和重复建站，形成当前需求中的首个正式商业版本。
- M5 增加用户级策略与报价，不阻塞固定 Auto 上线。

## 后续方向

多地区测评、供应商自助入驻、其他网关、同一供应商多套凭证、统一跨站账户和动态插件系统等待真实运营需求后再进入新里程碑。

## 模块设计规则

M0 已有三份模块文档；M1 已确认扩充这三个模块并新增人工策略、稳定价格、运营账号与权限、运营控制台四个模块。后续里程碑仍需在开始前结合对应架构分层讨论模块边界；用户确认后再创建对应文档并补齐双向链接。

## 进度依据

M0 已通过真实供应商和独立转发验收。M1 已实现多站运营接口、所有者会话、人工 Auto、独立价格版本、完整站点计划、并行同步和运营控制台；完整项目门禁、三供应商双站数据库流程、双 New API 进程合同、受控额度差异及桌面和手机核心界面流程已经通过。真实 3～5 家供应商向两个目标站点投放、实际账单抽样，以及控制台中的 Auto 发布、价格发布和历史恢复完整操作仍待验收，因此 M1 保持进行中。
